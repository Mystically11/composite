# Composite
Composite is a Chrome browser extension for manipulating audio, such as its playback speed and pitch.

<img width="328" alt="Screenshot" src="https://github.com/user-attachments/assets/65f8021c-31c3-4c5c-a41b-741a903b45c6" />

## Why?
A couple extensions like this already exist, but they run on a subscription model for some reason, and one day one of those extensions asked me to pay to actually use the "essential and free" features
so I just ended up making my own. Turns out it's just 500 lines of code. Great. Paying a subscription for 500 lines of code.
